SUSMITHA DEVI - UPDATED PORTFOLIO

HOW TO OPEN (NO MAVEN / NO MYSQL NEEDED)
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. If it does not open, right-click index.html > Open with > Google Chrome.

This is a simple static portfolio made with HTML and CSS. It does not need Java, Maven, MySQL, or a server.

Included:
- Dark responsive portfolio
- 7 clickable public GitHub repository links
- 3 NPTEL course scores
- Education, skills, projects and contact details

To edit:
- Open index.html in Notepad or VS Code to change text and links.
- Open style.css to change colours and layout.

Note: The private FileUploadSystem repository is intentionally not displayed.
